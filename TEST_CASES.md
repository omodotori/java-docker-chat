# Тест-кейсы для Java Docker Chat Application

## Общая информация

- **Проект**: Java Docker Chat Server
- **Технологии**: Spring Boot 3.2.1, WebSocket (STOMP), PostgreSQL, Docker
- **Дата создания**: 2026-01-30

---

## TC-01: Подключение пользователя к чату

| Параметр        | Значение                                                           |
| --------------- | ------------------------------------------------------------------ |
| **ID**          | TC-01                                                              |
| **Название**    | Подключение пользователя к чату                                    |
| **Приоритет**   | Высокий                                                            |
| **Предусловия** | Сервер запущен, браузер открыт на http://localhost:8080/index.html |

### Шаги выполнения:

1. Открыть страницу http://localhost:8080/index.html
2. Ввести имя пользователя "TestUser" в поле ввода
3. Нажать кнопку "Start Chatting"

### Ожидаемый результат:

- Страница входа скрывается
- Отображается chat room с заголовком "Spring Boot Chat Room"
- В области сообщений появляется уведомление "TestUser joined!"

### Шаги выполнения:

## TC-10: Отображение timestamp сообщений

| Параметр        | Значение                                 |
| --------------- | ---------------------------------------- |
| **ID**          | TC-10                                    |
| **Название**    | Корректное отображение времени сообщений |
| **Приоритет**   | Низкий                                   |
| **Предусловия** | Пользователь в чате                      |

### Шаги выполнения:

1. Отправить сообщение
2. Проверить формат времени под сообщением

### Ожидаемый результат:

- Время отображается в формате HH:MM (например, "14:30")
- Время соответствует локальному времени пользователя
